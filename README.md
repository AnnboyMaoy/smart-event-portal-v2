# Smart Event Portal (PHP + MySQL)

1. Install XAMPP (PHP 7.4+). Start **Apache** and **MySQL**.
2. Copy this folder to `C:\xampp\htdocs\smart-event-portal`
3. Open http://localhost/phpmyadmin > SQL tab > paste `database.sql` > Go
4. Open http://localhost/smart-event-portal/
